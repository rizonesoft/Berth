2. **P2** `scripts/check-all.ps1:35` sets `$ErrorActionPreference = 'Stop'` while inheriting `$PSNativeCommandUseErrorActionPreference`. In PowerShell 7.4 or later, set the latter to `$true` and invoke `.\scripts\check-all.ps1 -Only test` with a failing test. The native invocation throws before the script reads `$LASTEXITCODE`, losing the promised `FAILED test:` line and exit-code handling. I verified that this preference combination throws on a native exit of 7 before the following statement executes. Set `$PSNativeCommandUseErrorActionPreference = $false` in script scope so the gate handles native statuses itself.
